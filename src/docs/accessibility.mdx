# Accessibility

Every component is tested against **WCAG AA 2.2** standards:

- **4.1.2** — Correct roles, names, and states exposed to assistive technology
- **2.5.8** — Minimum target size of 24×24 CSS pixels for all interactive elements
- **2.1.1** — Full keyboard operability (Enter, Space, Arrow keys, Escape)
- **2.1.2** — No keyboard traps
- **1.3.1** — Semantic structure (headings, landmarks, lists)
- **2.5.3** — Label in name (visible labels preferred over `aria-label`)

## Validation

Accessibility is validated at two levels:

1. **axe-core audits** — automatic via the Storybook a11y addon on every story
2. **Interaction tests** — `play` function tests that assert ARIA attributes, keyboard behavior, and target sizes in a real browser
