# @ravl/base-ui-tailwind

A **React 19** design system built for accessibility, composability, and themability.

This library provides a set of production-ready UI components that are **WCAG AA 2.2 compliant** out of the box. The goal is to give teams a solid foundation they can theme and extend — without sacrificing accessibility or developer experience.

Components are organized into two layers:

- **Ingredients** — Low-level primitives (Button, Dialog, Select, Tabs, etc.) that handle ARIA semantics, keyboard navigation, and focus management. These are the building blocks.
- **Recipes** — Opinionated composites (Form, and more to come) that combine ingredients and enforce accessibility requirements like visible labels, error messaging, and proper `aria-describedby` associations.
