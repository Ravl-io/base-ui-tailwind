# Technology

- **Primitives** — [Base UI](https://base-ui.com) (`@base-ui/react`) — unstyled, accessible React components
- **Styling** — [Tailwind CSS v4](https://tailwindcss.com) with CSS custom properties and OKLCh color space
- **Variants** — [class-variance-authority](https://cva.style) (CVA) for prop-driven variant styling
- **Class merging** — `clsx` + `tailwind-merge` via a shared `cn()` utility
- **Icons** — [Lucide React](https://lucide.dev)
- **Docs & testing** — [Storybook 10](https://storybook.js.org) with `addon-a11y` (axe-core) and `addon-vitest`
